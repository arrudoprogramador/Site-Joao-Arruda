# Meu Portfólio Pessoal

Este projeto consiste no desenvolvimento do meu portfólio profissional, criado com foco em apresentar minhas habilidades, projetos, tecnologias e trajetória como desenvolvedor de software.

A aplicação foi construída utilizando tecnologias modernas do ecossistema web, priorizando desempenho, organização de código e uma experiência visual agradável para os visitantes.

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Vite
* ESLint
* Prettier

## 🎯 Objetivo

Este portfólio foi desenvolvido para consolidar conhecimentos em desenvolvimento front-end, demonstrar projetos pessoais e servir como uma vitrine profissional para recrutadores, empresas e outros desenvolvedores.
